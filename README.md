# Employee Workforce Segmentation

## Project Overview
This project applies unsupervised machine learning to group employees based on similarities in workforce data.

## Objectives
- Segment employees using K-Means clustering.
- Compare the results with Hierarchical Clustering.
- Apply Principal Component Analysis (PCA) to reduce dimensions.
- Analyze department-level workforce segments and performance groups.
- Explore cluster-level employee attrition and retention patterns.
- Build a workforce analytics dashboard.

## Technologies Used
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn and Google Colab.

## Deliverables
- Employee Segmentation Report
- PCA Summary
- Workforce Analytics Dashboard

## Dataset
IBM HR Analytics Employee Attrition & Performance dataset, sourced from Kaggle.
